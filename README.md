# Telegram Bot Webhook (FastAPI + Aiogram 3)
این پروژه یک ربات تلگرام است که با استفاده از Aiogram 3 و FastAPI ساخته شده و روی Render با Webhook اجرا می‌شود.
ربات دارای قابلیت‌های خوش‌آمدگویی، خداحافظی و حذف پیام‌های دارای لینک است
.
🚀 قابلیت‌ها
خوش‌آمدگویی خودکار به اعضای جدید
خداحافظی خودکار هنگام خروج اعضا
حذف پیام‌های دارای لینک (ضد تبلیغات و ضد اسپم)
استفاده از Webhook برای سرعت و پایداری بیشتر
سازگار با Render و قابل بیدار نگه‌داشتن با UptimeRobot
ساخته‌شده با Aiogram 3 + FastAPI
